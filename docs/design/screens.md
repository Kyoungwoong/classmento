# 화면 설계 (텍스트 와이어)

각 화면 = `Screen` + `ScreenTitle` + 본문 + `BottomCTA`. 경로는 App Router 기준.

## 1. 홈 `/` (구현됨)
- 제목: "이력서 한 장으로\n실전 면접을 준비해요" / 설명: "질문부터 피드백까지 15분이면 충분해요."
- 본문: 3단계 ListRow(번호 원 + 제목 + 설명)
- CTA: [이력서 올리기] · 캡션 "PDF, DOCX 파일 · 최대 20MB"

## 2. 이력서 업로드 `/resume/upload`
- 제목: "이력서를 올려주세요"
- 본문: 파일 선택 영역(`bg-bg-muted` 면, 점선 금지) → 선택 후 파일명·용량 ListRow
- CTA: [올리기] (파일 없으면 disabled)
- 로딩: 전체 화면 "이력서를 읽고 있어요" + 진행 막대(불확정)

## 3. 파싱 결과 확인 `/resume/[id]`
- 제목: "이렇게 정리했어요\n틀린 곳이 있으면 고쳐주세요"
- 본문: 섹션(경력 / 기술 / 프로젝트) 각각 소제목(`text-title2`) + ListRow. 행 탭 → 바텀시트 수정
- CTA: [면접 준비하기]

## 4. 면접 유형 선택 `/interview/new`
- 제목: "어떤 면접을 볼까요?"
- 본문: 선택형 ListRow 2개(기술 면접 / 인성 면접, 설명 한 줄). 선택 시 `bg-primary-weak` + 오른쪽 체크
- 질문 수: 3 / 5 / 7 세그먼트
- CTA: [질문 만들기] → 로딩 "이력서에서 질문을 고르고 있어요"

## 5. 면접 진행 `/interview/[id]/q/[seq]`  (숨고식 단계 폼)
- 상단: ProgressBar + "2 / 5"
- 제목 자리에 질문 문장(`text-title1`)
- 본문: 녹음 상태(대기 / 녹음 중 경과시간 큰 숫자 / 완료 후 다시 듣기)
- CTA: 대기 [답변 시작하기] → 녹음 중 [답변 끝내기](danger 아님, primary) → 완료 [다시 녹음](secondary) + [다음 질문]
- 마이크 권한 거부 시: 안내 문구 + [설정 방법 보기]

## 6. 결과 리포트 `/interview/[id]/report`
- 제목: "면접이 끝났어요" + 종합 점수 큰 숫자(예: 3.8 / 5)
- 본문: 강점 1줄, 보완점 1줄 → 문항별 ListRow(질문 요약 + 점수) → 탭하면 상세
- 상세 `/interview/[id]/report/[seq]`: 내 답변(STT 텍스트), 기준별 점수 막대, 잘한 점 / 고칠 점 / 이렇게 답해보세요
- CTA: [다시 연습하기]
