# 화면 설계 (텍스트 와이어)

각 화면 = `Screen` + `ScreenTitle` + 본문 + `BottomCTA`. 경로는 App Router 기준.

## 1. 홈 `/` (구현됨, 노트 콘셉트 ADR 0007)
- 표지(모눈 `GridPaper` + 종이 면): 라벨 "말로 답하는 모의면접" → h1 "면접은 말로 하니까,
연습도 **말로** 해요"(형광펜 한 단어) → 설명 → [면접 시작하기](주요) + [이력서 올리기](보조)
  - 오른쪽 `figure` "면접 노트 미리보기"(lg부터 2단, 그 아래 폭에서는 문구 아래): 노트 한 장("질문 2" + 질문 + 녹음 파형 + 잘한 점) + 채점 도장 4.2 + 마스코트 happy
  - 로그인했고 면접이 있으면 표지 아래 "최근 면접" 패널
- 오늘의 면접 준비(lg부터 노트 8칸 + 포스트잇 4칸, 그 아래 폭에서는 쌓기): 노트 한 장 + `CheckList`(이력서 올리기 · 면접 고르기 · 말로 답하기 · 채점 받기) + 포스트잇 "처음이라면 — 질문 세 개면 10분 안에 끝나요."
- 면접 종류: h2 "네 가지 면접 중에 골라요"(손 밑줄) + 색인 탭 4장(경험·기술·인성·혼합, 탭 색 연두(primary)·남색 연한 면(navy-100)·연한 연두(lime-200)·남색 회색(navy-200))
- 칠판(남색 면 + 테두리): 손글씨 h2 "오늘은 질문 세 개만 답해 볼까요?" + "이력서가 없어도 바로 시작할 수 있어요." + [면접 시작하기](보조)

## 1-1. 로그인 `/login` (구현됨)
- 모눈 바탕 위 노트 한 장(`NoteSheet`) 안에 폼. 제목 옆 마스코트 idle, 노트 첫 줄 손글씨 "다시 왔네요!"(회원가입은 "첫 장을 펼쳐요")
- 상단: 뒤로 가기(TopBar)
- 제목: "이메일로\n로그인해 주세요"
- 본문: 이메일·비밀번호 TextField. 그 아래 "처음이신가요? **회원가입**" 링크
  - 소셜 키가 설정돼 있으면 "간편하게 시작하기" + 회색 면 버튼(예: "카카오로 계속하기")
- CTA: [로그인] (두 칸이 다 차야 활성). 실패하면 비밀번호 아래에 빨간 문장
- 로그인 후에는 `next` 경로로 이동한다(내부 경로만 허용).

## 1-2. 회원가입 `/signup` (구현됨)
- 제목: "반가워요\n몇 가지만 알려주세요"
- 본문: 이름 / 이메일 / 비밀번호(8자 이상, 입력 중 즉시 안내). 이미 가입된 이메일이면 이메일 칸에 에러를 띄운다.
- CTA: [가입하기] → 가입과 동시에 로그인되고 `next`로 이동한다.

## 2. 이력서 업로드 `/resume/upload` (구현됨)
- 제목: "이력서를 올려주세요" / 설명: "경력, 기술, 프로젝트를 자동으로 정리해 드려요."
- 본문: 파일 선택 면(`bg-bg-muted`, 점선 금지, "파일 고르기")
  - 선택 후: 형식 배지(PDF/DOCX) + 파일명·용량 ListRow + "바꾸기"
  - 형식·용량 오류는 즉시 빨간 문장으로 보여준다.
- CTA: [올리기] (파일이 없으면 비활성). 캡션 "올린 이력서는 면접 질문을 만드는 데만 써요"

## 3. 파싱 결과 확인 `/resume/[id]` (구현됨)
- 처리 중: "이력서를 읽고 있어요" + ProgressBar(30% → 70%) + 단계 문장 2개("글자를 읽고 있어요" / "경력과 기술을 정리하고 있어요"), 1.5초마다 폴링
- 실패: "이력서를 읽지 못했어요" + 사유 + CTA [다시 올리기]
- 완료:
  - 제목: "이렇게 정리했어요\n빠진 기술이 있으면 더해 주세요" + 파일명 (행 수정이 생기면 "틀린 곳이 있으면 고쳐주세요"로)
  - 처음 불러오는 중에는 "이력서를 불러오고 있어요"(처리 중 화면과 구분), 404는 [이력서 올리기], 그 외 에러는 [다시 시도하기]
  - 섹션(`text-title2` + 개수): 기본 정보 / 기술(Chip, 지우기·추가 가능) / **경험** / 학력. 비어 있으면 "찾지 못했어요"
  - **경험**(ADR 0005):
    - 경력·프로젝트 하나씩을 배너로 보여준다(`ExperienceBanner`).
    - 배너는 회색 면 한 장이다. 위에 종류 · 기간, 가운데 제목, 그 아래 요약 2줄과 기술 Chip(sm, 최대 4개 + "+N")을 둔다.
    - 지금은 보여주기만 하고, 면접 기능에서 고를 수 있게 한다(선택 시 `bg-primary-weak` + 체크 예정).
    - 상태:
      - 불러오는 중
      - 불러오기 실패 / 나누기 실패 + [다시 시도하기]
      - 이전 버전으로 정리돼 비어 있음: "이 이력서는 경험별로 아직 정리하지 않았어요" + [경험으로 나누기]
      - 나눴는데 0건: "경력·프로젝트를 찾지 못했어요"
  - CTA: 고친 게 있으면 [고친 내용 저장하기] → Toast "저장했어요". 없으면 [면접 준비하기](질문 생성 기능 전까지 비활성, 캡션 안내)
- 예정: 경험 배너에서 원문(하이라이트·설명)을 펼쳐 보고 고치기. 지금은 결과 화면에서 경력·프로젝트 원문을 볼 수 없고, 저장할 때는 원문이 그대로 유지된다.

## 3-1. 관리자 (구현됨, ADMIN만. 권한이 없으면 제목 자리에 "관리자만 볼 수 있어요.")
- `/admin` 메뉴: 상단 오른쪽 로그아웃. 제목 "무엇을 관리할까요?" + ListRow(질문 은행 / 카테고리 / 회원, 오른쪽 화살표)
- `/admin/users`: 제목 "회원이 N명 있어요" / "최근 가입한 순서예요." ListRow(이름 / 이메일 · 가입방식 · 가입일, 관리자는 오른쪽 회색 "관리자")
- `/admin/categories`: 제목 "카테고리를 정리해요"
  - 대분류마다 섹션(큰 이름 + 이름 바꾸기·숨기기 텍스트 버튼)
  - 소분류 행: 이름 / "질문 N개 · 숨김", 오른쪽 숨기기·다시 보이기(실패하면 그 행 아래 에러). 이름을 누르면 그 자리에서 이름 바꾸기 폼
  - 섹션 끝 "소분류 추가하기", 맨 끝 "대분류 추가하기"(누르면 인라인 TextField)
- `/admin/questions`: 제목 "질문이 N개 있어요" / "최근에 넣은 순서예요."
  - 필터(위에서 아래로): 대분류 ChipGroup(줄바꿈, 못 불러오면 "카테고리를 불러오지 못했어요" + [다시 불러오기]) → 고르면 소분류 ChipGroup → 난이도 SegmentedControl(전체 포함) → 검색 TextField(0.3초 뒤 반영) → "숨긴 질문도 보기" Toggle
  - 목록: ListRow(질문 2줄 / 소분류 · 난이도 · 태그 · 숨김), 누르면 수정 화면. 20개씩 "더 보기"
  - CTA [CSV로 올리기](보조) + [질문 추가하기]. 상태: 불러오는 중 / "조건에 맞는 질문이 없어요" / 실패 + [다시 시도하기]
- `/admin/questions/new`, `/admin/questions/[id]`: 제목 "어떤 질문을 넣을까요?" / "질문을 고쳐요"
  - 대분류 → 소분류 SelectChip(숨긴 카테고리는 지금 질문이 있는 곳만 보임)
  - 질문 TextArea(5~300) → 난이도 → 직무 SelectChip(여러 개) → TagInput → 질문 의도(선택)
  - 칸마다 에러는 그 칸 아래(스크린리더에 연결), 저장 시 첫 실패 칸으로 스크롤·포커스. 대분류를 안 골랐으면 대분류 묶음에 알림. 서버 규칙 오류(409 등)는 폼 아래 `role="alert"`
  - CTA: 새로 넣기 [저장하기] / 수정 [숨기기 또는 다시 보이기](보조) + [저장하기]
- `/admin/questions/import`: 제목 "CSV로 질문을 한꺼번에 넣어요" / "오류가 한 줄이라도 있으면 아무것도 저장하지 않아요."
  - "이렇게 만들어 주세요" 규칙 4줄 + [예시 파일 받기](BOM 붙은 UTF-8, 브라우저에서 만듦)
  - CSV 파일 칸(회색 면, 파일 이름 + [파일 고르기]/[바꾸기]). .csv가 아니거나 2MB 초과면 칸 아래 에러, 서버 거절(인코딩 등)은 `role="alert"`
  - CTA [올리기](파일을 고르기 전엔 비활성, "올리고 있어요")
  - 결과: 성공 "질문 N개를 넣었어요" + [목록으로 가기] / 오류 "N줄을 고쳐 주세요" + "아무것도 저장하지 않았어요…" + ListRow("3번째 줄" / 원인) + [다른 파일 고르기]
- 예정: 크레딧 조정

## 4. 면접 만들기 `/interview/new` (ADR 0005, 구현됨)
숨고식으로 한 화면에 한 질문씩 묻는다(종류 → 조건 → 질문 수, 인성은 조건 없음). TopBar 뒤로 가기는 이전 단계로.
- 데스크톱 2단(`Screen aside`, 왼쪽 sticky): 왼쪽 "새 면접 · 몇 가지만 고르면 바로 시작해요" + 단계 패널(`StepProgress`: 끝난 단계 연두 원+체크와 고른 값, 지금 단계 연한 연두 행, 남은 단계 남색 연한 원). 오른쪽 질문 + CTA
- 모바일: 왼쪽 열 대신 위에 얇은 ProgressBar

4-1. 종류 — 제목 "어떤 면접을 볼까요?" / "질문은 모두 말로 답해요."
- ChoiceRow 4개(radiogroup, 고르면 `bg-primary-weak` + 체크). 고를 때까지 [다음] 비활성
  - **경험 기반 면접** — "내 경험 하나를 골라 깊게 물어봐요". 고를 수 없을 때(비활성, 이유는 행 설명):
    - 불러오는 중 "이력서를 불러오고 있어요" / 실패 "이력서를 불러오지 못했어요" + 바로 아래 [다시 불러오기]
    - 올렸지만 정리 중 "이력서를 정리하고 있어요. 끝나면 고를 수 있어요"
    - 없음 "이력서가 필요해요" + 바로 아래 [이력서 올리러 가기]
  - **기술 면접** — "직무와 연차에 맞춰 기술·CS를 물어봐요"
  - **인성 면접** — "자기소개부터 협업 경험까지 물어봐요"
  - **기술 + 인성** — "실제 면접처럼 번갈아 물어봐요"

4-2. 조건
- 경험 기반: "어떤 경험으로 면접을 볼까요?" — (정리된 이력서가 여럿이면 이력서 SelectChip) → 경험 배너(radio, 고르면 연한 연두 면 + 체크). 불러오는 중 / 실패 alert + [다시 불러오기] / 경험 없음 "경험을 찾지 못했어요…" + [이력서 화면으로 가기]
- 기술·혼합: "어떤 직무로 볼까요?" — 직무 ChipGroup(공통 제외) + 연차 SegmentedControl. 기술은 이력서가 있으면 "내 이력서 기술로 좁히기" Toggle
- 안 고르고 [다음]이면 폼 아래 alert("경험을 하나 골라 주세요." / "직무와 연차를 골라 주세요.")

4-3. 질문 수 — "질문은 몇 개로 할까요?" / "질문 하나에 2~3분 정도 걸려요." SegmentedControl 3/5/7(기본 3)
- CTA [질문 만들기] → 로딩 "질문 은행에서 고르고 있어요" / 경험 기반 "경험을 읽고 질문을 만들고 있어요" → `/interview/{id}`
- 실패(질문 부족 409 등)는 폼 아래 alert로 서버 문구

진입점: 홈 [바로 면접 보기](보조) + [이력서 올리기], 이력서 화면 [면접 준비하기]

## 5. 면접 진행 `/interview/[id]` (구현됨, 한 페이지 안에서 질문 전환)
- 데스크톱 2단: 왼쪽(sticky) ProgressBar + "2 / 5" → 노랑 배지 "기술 질문"/"인성 질문" → 질문 문장(h1, `title1-lg`). 오른쪽 녹음 패널(가운데 정렬): 마스코트 + 상태 문구·타이머·다시 듣기·alert, 패널 아래 CTA
- 모바일: 질문 → 녹음 패널 순으로 쌓고 CTA는 하단 고정
- 마스코트 표정: 녹음 중 `listening` · 올리기/끝내기 중 `thinking` · 오류 `oops` · 그 밖 `idle`. 불러오는 중 `thinking`, 불러오기 실패 `oops`
- 시작은 아직 답하지 않았거나 실패한 첫 질문(나갔다 와도 이어서). 끝난 면접이면 리포트로
- 녹음 상태(`useRecorder`, 3분이면 저절로 멈춤):
  - 대기: "준비되면 답변을 시작해요. 결론부터 말해 보세요." → CTA [답변 시작하기]
  - 마이크를 켜는 중: [답변 시작하기]가 로딩("마이크를 켜고 있어요"), 다시 누를 수 없음
  - 녹음 중: 경과 시간 큰 숫자(mm:ss, `text-display`) + "녹음하고 있어요. 3분이 되면 저절로 멈춰요." → [답변 끝내기]
  - 녹음됨: `<audio>` 다시 듣기 → [다시 녹음](보조) + [다음 질문] / 마지막은 [면접 끝내기]
- 올리기 실패: alert "답변을 올리지 못했어요…" + 버튼이 [다시 올리기]
- 모든 질문을 이미 올렸으면(새로고침·끝내기 실패 뒤): "모든 질문에 답했어요. 면접을 끝내면 리포트를 볼 수 있어요." + [면접 끝내기]만(다시 녹음하지 않음). 끝내기 실패면 [다시 끝내기]
- 불러오기 실패: 없는 면접이면 [새 면접 만들기], 그 밖은 [다시 불러오기]
- 끝내기:
  - 서버가 아직 글자로 바꾸는 중(409 `ANSWERS_PROCESSING`)이면 "정리하고 있어요"로 2초마다 다시(화면을 떠나면 멈춤)
  - 다시 녹음해야 하는 답변(409 `ANSWERS_FAILED`)이 있으면 그 질문으로 돌아가 원인을 alert로
  - 끝나면 `/interview/{id}/report`
- 마이크 거부: alert "마이크를 쓸 수 없어요. 주소창의 마이크 권한을 허용한 뒤 다시 시도해 주세요." + [다시 시도하기]. 지원하지 않는 브라우저 안내도 같은 자리

## 6. 결과 리포트 `/interview/[id]/report` (구현됨)
- 평가 중(`EVALUATING`): 제목 "답변을 평가하고 있어요" + "끝나면 이 화면에 바로 보여 드려요." 3초마다 다시 불러온다(종합이 빠졌으면 서버가 이때 다시 만든다)
- 머리 띠(`Section tone="tint" compact`): "면접 리포트"(eyebrow) + 제목 + 오른쪽 마스코트(끝 `happy` / 평가 중 `thinking`)
- 끝(`READY`): 제목 "면접이 끝났어요" + 종합 점수 큰 숫자(`text-hero`, `3.8 / 5`) → 잘한 점 / 보완할 점 흰 패널 2개(데스크톱 나란히)
- 아래 2단(`TwoColumn` sticky): 왼쪽 "기준별 점수" 패널(`ScoreBar` 기준별 평균, 평가 전이면 "평가가 끝나면 기준별 점수가 보여요.") · 오른쪽 "문항별" 패널 + CTA
- 문항별: ListRow(“1. 질문”, 오른쪽에 점수 "3.0점"(body1 굵게) / 설명 "평가하고 있어요"·실패 원인·"답하지 않았어요") → 탭하면 상세. 실패한 문항 아래 텍스트 버튼 [다시 평가하기], 요청이 실패하면 그 아래 alert
- 평가 중 다시 불러오기가 실패하면 폴링을 멈추고 머리 띠 안 alert + [다시 불러오기]. 처음 불러오기 실패면 CTA가 [다시 불러오기](없는 리포트면 [다시 연습하기])
- CTA: [다시 연습하기] → `/interview/new`. 불러오기 실패·없는 리포트는 제목에 원인
- 상세 `/interview/[id]/report/[seq]`
  - 데스크톱 2단. 왼쪽: "N번 질문"(eyebrow) + 질문(제목) + "이 질문으로 보려는 것: 의도"(설명) → 내 답변: `<audio>` 다시 듣기(본인만) + STT 텍스트(회색 면 한 덩어리)
  - 오른쪽 패널들: 기준별 점수(`ScoreBar` + 근거 인용 “…”) → 잘한 점 / 고칠 점 → "이렇게 답해 보세요"(연한 연두 패널, 강조 하나). 평가 중이면 안내 문구, 실패면 원인 패널
  - CTA: [목록으로 가기]. 없는 문항이면 "문항을 찾을 수 없어요", 불러오기 실패면 [다시 불러오기]
- 홈 "최근 면접"(로그인했고 면접이 있을 때만, 최근 3개): 유형 · 날짜 · 질문 수 → 진행 중이면 [이어서 하기](`/interview/{id}`), 끝났으면 [리포트 보기]
