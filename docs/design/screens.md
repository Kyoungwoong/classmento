# 화면 설계 (텍스트 와이어)

각 화면 = `Screen` + `ScreenTitle` + 본문 + `BottomCTA`. 경로는 App Router 기준.

## 1. 홈 `/` (구현됨)
- 제목: "이력서 한 장으로\n실전 면접을 준비해요" / 설명: "질문부터 피드백까지 15분이면 충분해요"
- 본문: 3단계 ListRow(번호 원 + 제목 + 설명)
- CTA: [이력서 올리기] → `/resume/upload`. 로그인하지 않았으면 `proxy.ts`가 `/login?next=...`로 보낸다. 캡션 "PDF, DOCX 파일 · 최대 20MB"

## 1-1. 로그인 `/login` (구현됨)
- 상단: 뒤로 가기(TopBar)
- 제목: "이메일로\n로그인해 주세요"
- 본문: 이메일·비밀번호 TextField. 그 아래 "처음이신가요? **회원가입**" 링크
  - 소셜 키가 설정돼 있으면 "간편하게 시작하기" + 회색 면 버튼(예: "카카오로 계속하기")
- CTA: [로그인] (두 칸이 다 차야 활성). 실패하면 비밀번호 아래에 빨간 문장
- 로그인 후에는 `next` 경로로 이동한다(내부 경로만 허용).

## 1-2. 회원가입 `/signup` (구현됨)
- 제목: "반가워요\n몇 가지만 알려주세요"
- 본문: 이름 / 이메일 / 비밀번호(8자 이상, 입력 중 즉시 안내). 이미 가입된 이메일이면 이메일 칸에 에러를 띄운다.
- CTA: [가입하기] → 가입과 동시에 로그인되고 `next`로 이동한다.

## 2. 이력서 업로드 `/resume/upload` (구현됨)
- 제목: "이력서를 올려주세요" / 설명: "경력, 기술, 프로젝트를 자동으로 정리해 드려요."
- 본문: 파일 선택 면(`bg-bg-muted`, 점선 금지, "파일 고르기")
  - 선택 후: 형식 배지(PDF/DOCX) + 파일명·용량 ListRow + "바꾸기"
  - 형식·용량 오류는 즉시 빨간 문장으로 보여준다.
- CTA: [올리기] (파일이 없으면 비활성). 캡션 "올린 이력서는 면접 질문을 만드는 데만 써요"

## 3. 파싱 결과 확인 `/resume/[id]` (구현됨)
- 처리 중: "이력서를 읽고 있어요" + ProgressBar(30% → 70%) + 단계 문장 2개("글자를 읽고 있어요" / "경력과 기술을 정리하고 있어요"), 1.5초마다 폴링
- 실패: "이력서를 읽지 못했어요" + 사유 + CTA [다시 올리기]
- 완료:
  - 제목: "이렇게 정리했어요\n빠진 기술이 있으면 더해 주세요" + 파일명 (행 수정이 생기면 "틀린 곳이 있으면 고쳐주세요"로)
  - 처음 불러오는 중에는 "이력서를 불러오고 있어요"(처리 중 화면과 구분), 404는 [이력서 올리기], 그 외 에러는 [다시 시도하기]
  - 섹션(`text-title2` + 개수): 기본 정보 / 기술(Chip, 지우기·추가 가능) / 경력 / 프로젝트 / 학력. 비어 있으면 "찾지 못했어요"
  - CTA: 고친 게 있으면 [고친 내용 저장하기] → Toast "저장했어요". 없으면 [면접 준비하기](질문 생성 기능 전까지 비활성, 캡션 안내)
- 예정: 경력·프로젝트 행을 탭하면 바텀시트에서 수정

## 3-1. 관리자 `/admin` (구현됨, ADMIN만)
- 상단 오른쪽: 로그아웃 텍스트 버튼
- 제목: "회원 N명" / "최근 가입한 순서예요."
- 본문: ListRow(이름 / 이메일 · 가입방식 · 가입일, 관리자는 오른쪽에 "관리자")
- 권한이 없으면 제목 자리에 "관리자만 볼 수 있어요."
- 예정: 질문 은행 관리, 크레딧 조정

## 4. 면접 유형 선택 `/interview/new` (ADR 0004)
숨고식으로 한 화면에 한 질문씩 묻는다. 유형에 따라 다음 단계가 달라진다.

4-1. 유형 — 제목 "어떤 면접을 볼까요?"
- 선택형 ListRow 4개. 선택하면 `bg-primary-weak` + 오른쪽 체크
  - **기술 면접** — "직무와 기술을 고르면 맞춰서 물어봐요"
  - **이력서 기반 기술 면접** — "내 이력서의 프로젝트를 깊게 물어봐요" (이력서가 없으면 설명에 "이력서가 필요해요")
  - **꼬리질문 면접** — "내 답변을 듣고 계속 파고들어요"
  - **인성 면접** — "자기소개부터 협업 경험까지 물어봐요"
- CTA: [다음]

4-2. 유형별 조건
- 기술: "어떤 직무인가요?"(직무 ListRow) → "경력은 얼마나 되나요?"(신입/1~3년/4~7년/8년+) → "어떤 기술을 물어볼까요?"(Chip 다중 선택 + "CS 기초도 포함" 토글)
- 이력서 기반: "어떤 이력서로 볼까요?"(내 이력서 ListRow, 없으면 [이력서 올리기])
- 꼬리질문: "무엇을 파고들까요?"(이력서 프로젝트 또는 기술 Chip 중 1개) → 깊이 3 / 5 세그먼트
- 인성: 바로 질문 수로
- 질문 수(꼬리질문 제외): 3 / 5 / 7 세그먼트
- CTA: [질문 만들기] → 로딩(유형별): "질문 은행에서 고르고 있어요" / "이력서에서 질문을 고르고 있어요" / "첫 질문을 준비하고 있어요"

## 5. 면접 진행 `/interview/[id]/q/[seq]`  (숨고식 단계 폼)
- 상단: ProgressBar + "2 / 5"
- 제목 자리에 질문 문장(`text-title1`)
- 본문: 녹음 상태(대기 / 녹음 중 경과시간 큰 숫자 / 완료 후 다시 듣기)
- CTA: 대기 [답변 시작하기] → 녹음 중 [답변 끝내기](danger 아님, primary) → 완료 [다시 녹음](secondary) + [다음 질문]
- 마이크 권한 거부 시: 안내 문구 + [설정 방법 보기]
- **꼬리질문 유형:**
  - 상단은 "2 / 5" 대신 "깊이 2"를 표시하고, 질문 위에 직전 답변 요약 한 줄("방금 '캐시 무효화'를 말씀하셨는데요")을 둔다.
  - [답변 끝내기]를 누르면 "다음 질문을 고르고 있어요"(8초 목표)를 거쳐 다음 질문으로 간다. AI가 끝내면 결과로 간다.

## 6. 결과 리포트 `/interview/[id]/report`
- 제목: "면접이 끝났어요" + 종합 점수 큰 숫자(예: 3.8 / 5)
- 본문: 강점 1줄, 보완점 1줄 → 문항별 ListRow(질문 요약 + 점수) → 탭하면 상세
- 상세 `/interview/[id]/report/[seq]`: 내 답변(STT 텍스트), 기준별 점수 막대, 잘한 점 / 고칠 점 / 이렇게 답해보세요
- CTA: [다시 연습하기]
