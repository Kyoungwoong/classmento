# ADR 0006: 디자인 방향 전환 — 연두 메인 · 웹사이트형 레이아웃 · 마스코트

- 상태: 채택 (2026-11-10)
- 대체: 첫 디자인 시스템의 원칙 "모바일 폭 단일 컬럼", "색은 회색 + 블루 하나", "카드·장식 금지"

## 결정
- **색**
  - 메인: 밝은 연두 `#A3E635`(면·버튼)
  - 글자와 제목: 남색 `#14213D`(연두 버튼의 글자, 헤더·푸터 면)
  - 연한 면: `#F4FCE3`
  - 포인트: 노랑 `#FACC15`(조금만)
  - 블루는 쓰지 않는다.
- **레이아웃**
  - 상단 사이트 헤더(로고·메뉴·로그인)와 남색 푸터가 있는 웹사이트로 바꾼다.
  - 본문 폭은 1120px, 데스크톱은 2단이다. 폼·로그인만 560px로 가운데 둔다.
- **구분**: 섹션은 배경 띠 색으로, 묶음은 테두리 패널(`Panel`)로 나눈다.
- **그림**: lucide 아이콘, 과정 일러스트, 표정이 바뀌는 마스코트를 쓴다.
- **유지**: 문구 톤, 터치 44px, 토큰만 쓰기, 그라데이션·글래스·이모지·보라 금지

## 이유
- 사용자 피드백(2026-11-09):
  - "밋밋하다."
  - "웹앱처럼 만들어놨다."
  - "색이 너무 없다. 미니멀은 좋지만 지금은 너무 없다."
- 모바일 폭 한 줄을 데스크톱에도 그대로 쓰니 화면 대부분이 비었다. 모의면접은 데스크톱에서 마이크를 켜고 쓰는 일이 많다.
- 참고 사이트: storify.kr. 헤더·메뉴, 띠 섹션, 2단, 패널, 과정 일러스트와 캐릭터를 쓴다. 그대로 따라 하지는 않고 구성만 가져온다.

## 결과
- 토큰 `primary`는 연두다. 연두는 흰 바탕에서 글자로 읽히지 않으므로(대비 1.5:1) 글자 강조는 `accent`(#4D7C0F)로 나눴다.
- `Screen`은 `width="site|narrow"`를 받는다. `BottomCTA`는 모바일에서만 하단에 고정된다.
- 새 공통 컴포넌트를 추가했다: `Section`, `Panel`, `TwoColumn`, `StepList`, `SiteHeader`·`SiteFooter`, `Mascot`
- 대비(WCAG AA 4.5:1)

  | 조합 | 대비 |
  |---|---|
  | 남색 글자 / 연두 버튼 | 10.6:1 |
  | accent / 흰색 | 5.0:1 |
  | accent / 연한 면 | 4.7:1 |
  | 연한 남색 글자 / 남색 푸터 | 13.3:1 |
  | 회색 보조 글자(`text-sub`) / 연한 면 | **4.4:1**: 연한 면 위 본문은 `text-text`를 쓴다 |
  | 연두 글자 / 남색 면 | 10.6:1: 연두를 글자로 쓰는 곳은 남색 면 위뿐이다 |
