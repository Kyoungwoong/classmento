# ADR 0007: 시각 콘셉트 "면접 노트"

- 상태: 채택 (2026-11-10)
- 보완: ADR 0006 (색·웹사이트형 헤더·푸터·넓은 본문은 그대로 둔다)
- 대체: 0006의 "모든 화면을 띠 섹션 + 2단 + 테두리 패널로 나눈다"는 반복 구성

## 결정
- classmento의 모양은 **면접 준비 노트**다. 공부하듯 질문을 적고, 말로 답하고, 채점받는 노트 한 권으로 본다.
- 노트 부품(`frontend/src/components/note/`)
  - `GridPaper`: 모눈 바탕(SVG 패턴, 남색 아주 연한 선). 화면 맨 위 영역에만 깐다.
  - `NoteSheet`: 노트 한 장. 미색 종이 면, 윗변 스프링 구멍, 왼쪽 연두 여백선.
  - `Highlight`: 노랑 형광펜. 제목의 핵심어 하나에만 칠한다.
  - `Scribble`: 손으로 그은 연두 밑줄(SVG).
  - `HandNote`: 손글씨 폰트(Gaegu) 메모. 짧은 한마디 주석에만 쓴다(본문 금지).
  - `Stamp`: 채점 도장. 점수를 기울어진 원형 도장으로 찍는다.
  - `StickyNote`: 노랑 포스트잇 + 테이프. 화면마다 팁 하나에만 쓴다.
  - `CheckList`: 손으로 체크한 할 일 목록(준비 단계).
- 화면마다 노트의 다른 장면을 쓴다. 같은 배치를 반복하지 않는다.
  - 홈: 모눈 위 표지 문구 + 노트 한 장 미리보기 → 준비 체크리스트 → 면접 종류 색인 탭 → 칠판(남색) 마무리
  - 로그인·회원가입: 모눈 위 노트 한 장
  - 면접: 질문을 적은 노트 한 장, 리포트는 채점된 답안지(도장·형광펜·여백 메모)
- 손글씨·기울기·테이프는 **화면마다 한두 군데**만 쓴다. 본문·버튼·폼은 지금처럼 단정하게 둔다.

## 이유
- 사용자 피드백(2026-11-10): 참고로 준 사이트와 너무 비슷하다. 레퍼런스를 비슷하게 가져가면 복제다. 우리만의 창의성을 원한다.
- 띠·2단·패널은 흔한 구성이라 classmento다운 점이 없었다. 모의면접은 "준비하고 연습하고 채점받는" 공부라서 노트가 서비스의 성격과 맞는다.
- 사용자가 고른 콘셉트다(면접 노트 / 목소리와 대화 / 둘을 섞기 중에서).

## 결과
- 연두(메인)·남색·노랑 팔레트는 유지하고, 종이 면 `paper`와 모눈 선 `rule` 토큰을 더한다.
- 손글씨 폰트 Gaegu를 `next/font/google`로 자체 호스팅한다(`font-hand`).
- 금지 목록은 유지한다(그라데이션·글래스·이모지·보라). 모눈은 그라데이션이 아니라 SVG 패턴으로 그린다.
